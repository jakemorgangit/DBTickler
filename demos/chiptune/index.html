CHIPTUNE CART

Every sound on this page is synthesised live in your browser with the Web Audio API: two pulse waves, a triangle and a noise channel, the same four voices as the NES sound chip. No audio files. The whole engine is one 15 KB script you can drop into a game.

Use it in a game

      
Load chiptune.js, unlock audio on the first click or keypress (browsers block sound until then), and call it from your game loop.

      
const chip = new ChipTune();

startButton.onclick = () => {
  chip.unlock();
  chip.play(ChipTune.songs.overworld);
};

// in your game logic
if (player.touches(coin)) chip.sfx('coin');
if (boss.awake) chip.play(ChipTune.songs.boss);
if (paused) chip.stop();

    

    

      
Write your own tune

      
One step is a sixteenth note. Pitched lines are NOTE:steps with r for rests. Drum lines take one character per step: k kick, s snare, h hat.

      
const myTheme = {
  name: 'Title', bpm: 132,
  pulse1:   { duty: 0.25, vol: 0.15,
              line: 'C5:2 E5:2 G5:4 A5:2 G5:2 E5:4' },
  triangle: { vol: 0.3,
              line: 'C3:4 G2:4 A2:4 G2:4' },
  noise:    { vol: 0.3, line: 'k.h.s.h.k.h.s.hh' },
};
chip.play(myTheme);
